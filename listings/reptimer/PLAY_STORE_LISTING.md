# Play Console — 商品详情文案

> 直接复制到 Play Console → 主要商品详情。字数按 Play 的上限校过：
> 应用名 ≤30、简短说明 ≤80、完整说明 ≤4000。

## 应用名称（≤30）

```
RepTimer
```

## 简短说明（≤80）

```
Interval timer for sets and rounds. Big numbers, colour-coded phases, works offline.
```

（84 字符）

## 完整说明（≤4000）

```
Set how long you work, how long you rest, and how many rounds. Press start and put the phone
down.

BUILT FOR USE, NOT FOR SCREENSHOTS

Set rest to zero and the rest phase disappears entirely — it does not flash up as "0" before
moving on. The last round is not followed by a pointless rest countdown. The timer reads from the
clock rather than counting ticks, so it stays accurate even if the app is interrupted.

WHAT YOU GET

• Prepare, work and rest, repeated for as many rounds as you need
• Cycles with a longer break between them
• Save as many timers as you like, each with its own name
• Colour-coded phases — you can tell work from rest out of the corner of your eye
• Screen stays on while the timer runs
• Vibrates on every phase change

NO ADS. NO SIGN-UP. WORKS OFFLINE.

There are no adverts, no accounts and no in-app purchases.

PRIVACY

RepTimer does not ask for your name, email or phone number, and requests no camera,
microphone, location or contacts permission. See the privacy policy for the full detail.
```
