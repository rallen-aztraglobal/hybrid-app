# App Title
Color Stack

## Short Description
Fast color puzzle: stack matching colors, beat the timer, and set new high scores.

## Full Description
Color Stack is a clean, fast-paced arcade puzzle game built for short and fun sessions.

Your goal is simple:
- A color block appears each turn.
- Tap one of the stack columns to place it.
- Match the top color of a stack to score bigger combos.
- Reach the highest score before time and moves run out.

Why players love Color Stack:
- Smooth, modern UI with animated transitions
- Easy to play with one hand
- Quick rounds perfect for break-time gaming
- Performance-optimized for a lightweight install
- Play again instantly and chase your best score

Think fast, choose the right stack, and build the perfect color tower.
