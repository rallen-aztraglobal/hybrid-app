# ADR-0005: 图标管线——单张主图，服务端 fan-out

- **状态**：已采纳(2026-06-24)

## 背景
需求要 Xcode 式图标体验：拖一张主图、展示各尺寸该放哪、可裁剪到最佳尺寸。Android 每渠道需 5 档密度 × 方形/圆形/自适应前景 + `anydpi-v26` 配置，人肉切图易错、无校验。

## 决策
**前端裁剪、后端 fan-out**：
- 前端 `react-easy-crop` 方形裁剪，导出 **1024×1024 主图**上传；UI 用**九宫格槽位**展示各 density（48/72/96/144/192 方形 + 圆形 + 108~432 自适应前景），可单槽覆盖。
- 后端 `disintegration/imaging`（纯 Go）一张主图 fan-out 全部尺寸 + 圆形遮罩 + 安全区留边 + 生成 `anydpi-v26/ic_launcher.xml`，打 `res.zip` 存对象存储。
- CLI `pull` 下载 res.zip 解压到 flavor 目录。

## 理由
- 「人肉切 5~6 张」变「传 1 张」，消除尺寸/裁剪错误。
- 纯 Go imaging 保持后端二进制全静态（呼应 ADR-0001），简单场景画质足够。

## 后果
- ✅ 图标产出标准化、可校验（尺寸/正方形/透明边提示）。
- ➖ 高画质需求下 imaging 不及 libvips；若将来需要，可切 `h2non/bimg`（引入 cgo，放弃全静态）——届时另立 ADR。

## 备选
- **客户端全程生成**：浏览器图像处理弱、各端不一致，被否。
- **后端 sharp(Node)**：与 ADR-0001 去 Node 冲突，被否。
